# RG-03: ショートカットと操作の一貫性

2026-09-24。RG-02（`9c52f04`）に続く独立した変更。対象はSQLエディタ/結果/画面切り替えのキー操作のみ。保存形式、DB実行方式、依存ライブラリは変更しない。

## 既存の動作と決定

`SqlEditor.tsx`のCodeMirrorにCtrl/⌘+Enterで全文実行する割り当てがあった。Tab補完、Ctrl/⌘+Space候補表示、通常編集のキーと`App.tsx`の`/`検索は維持する。Ctrl+Tabはエディタ移動専用とし、画面切り替えはCtrl+Shift+Mへ分離する。

新しいキー一覧はREADMEの「キーボード操作」に記載。F5とCtrl+Enterは、選択範囲があってもSQL全文を実行する。既存動作の維持を優先し、選択範囲だけの実行は追加しない。キーと実行ボタンのツールチップに明示する。

## 実装

- `src/lib/shortcuts.ts`: IME変換/229、AltGraph、ダイアログ、SQL以外の入力欄を除外。認識したコマンドの既定動作を抑止し、長押し時は再実行しない。
- `QueryWorkspace.tsx`: ウィンドウのcapture段階でSQL領域内のコマンドを扱う。追加・終了・移動・実行・中断はボタンと同じ関数を呼ぶ。CodeMirror側の実行バインドは削除して二重配送を防ぐ。
- 実行不可状態でも認識したSQL画面のキーはブラウザへ渡さない。新規タブ、タブ終了、F5再読込などとの競合を避ける。SQL画面が非表示ならSQLコマンドは動かさない。
- Ctrl+Wは実行中/最後のタブを閉じず、未保存SQLには既存の破棄確認を出す。中断は現在タブの実行IDだけを対象にする。
- 新規・移動・アクティブタブ終了後のフォーカスをSQL入力へ戻し、続けてキー操作できるようにする。
- 結果領域をTabでフォーカス可能にし、領域内のAlt+左右で結果を移動する。ページサイズ選択中は通常のフォーム操作を優先し、SQL入力内のAlt+左右では結果を変更しない。
- `App.tsx`: Ctrl+Shift+Mで表示モードを切り替え、SQL入力/リレーションのナビゲーションへフォーカスを移す。`/`検索にもIMEと長押しの除外を追加。
- ボタン等のツールチップと`aria-keyshortcuts`に割り当てを表示する。
