## 更新の目安

| 変更                           | 同時に見直す文書                                 |
| ------------------------------ | ------------------------------------------------ |
| 機能追加・削除、画面や操作条件 | 機能一覧、画面設計、該当詳細設計                 |
| Tauriコマンド、引数、戻り値    | インターフェース、データモデル、呼出元の詳細設計 |
| 保存形式・移行・暗号化         | データモデル、接続／クエリ管理、共通仕様         |
| SQL許可条件、排他、上限、中断  | SQL実行、結果と出力、共通仕様、接続権限ガイド    |
| スキーマ取得・配置・プレビュー | スキーマと関係図、プレビュー、データモデル       |
| CSV・型・ファイル確定          | 結果と出力、インターフェース、共通仕様           |
| キー設定・エラー・ログ         | 共通部品、画面設計                               |
| 対応環境・ビルド・署名・配布   | 概要、共通仕様、Windowsリリース資料              |
| テスト追加、未確認事項の解消   | 該当詳細設計のテスト表、照合結果と調査コミット   |

仕様を更新したら調査日・対象コミット・範囲も更新し、相対リンクと図を確認する。過去の検証結果を新しいコードでの検証結果に読み替えない。
