# MySQL実接続テスト

`npm run test:mysql` はインストール済みのMySQLバイナリから専用サーバーを起動し、アプリ本体のRust処理を実際のTCP接続で検証します。DB応答のモックや画面テストではありません。既存のMySQLサービスには接続しません。

## 実行

WindowsではNode.js（今回の検証環境は20.18.0）、Rust/Tauriのビルド環境、MySQL Community Serverの `mysqld.exe` と `mysql.exe` が必要です。管理者権限、Windowsサービス登録、Dockerは不要です。

```powershell
$env:RELAGRID_MYSQL_BIN = 'C:/Program Files/MySQL/MySQL Server 26.7/bin'
$env:RELAGRID_MYSQL_VERSION = '26.7.0'
npm run test:mysql
```

`RELAGRID_MYSQL_VERSION` は実際に使用する3桁の完全なバージョンを指定します。バイナリと起動後のサーバー両方のバージョンを照合し、一致しなければ失敗します。バイナリを自動ダウンロードしたり、既存のインストールを更新したりしません。上記はこの端末で検証する固定バージョンです。製品の対象であるMySQL 8.0の検証結果とは区別してください。他のバージョンを使う場合もバージョンを明示して実行します。

## 自動実行する処理

1. 一意な一時ディレクトリに空のDBを初期化します。
2. ループバックの空きポートで専用mysqldを起動し、準備完了とデータディレクトリの一致を確認します。
3. `tests/fixtures/schema.sql` を一意な `relagrid_fixture_*` DBへ投入し、ランダムなパスワードで書き込み用・SELECT専用ユーザーを作成します。rootはこの隔離サーバーの初期化だけに使用します。
4. Rustテストを一度ビルドし、TLSなし・TLSありで各7件以上の実接続テストを実行します。
5. サーバー証明書をホスト名不一致・期限切れへ切り替え、各1件の拒否テストを実行します。同じサーバーへTLSなしでは接続できることも確認し、DB停止や認証失敗を証明書検証の成功と誤認しません。
6. 成功・失敗・通常の中断時に起動したプロセスを終了し、生成した一時データを削除します。

WindowsではMySQLの監視プロセスを無効化し、スクリプトが起動したPIDを直接管理します。強制的にスクリプト自体を終了した場合やOS停止時まで後片付けを保証するものではありません。ポートは起動ごとに選ぶため、複数回の実行や別のテスト用サーバーとの共存が可能です。ひとつのサーバー内ではCSVの一時テーブルとスキーマ件数の競合を防ぐため直列実行します。

## 検証内容

| ケース               | 確認内容                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| スキーマ・プレビュー | テーブル、主キー、外部キー、日時・数値・NULL・バイナリ・日本語                                       |
| SQL結果              | Unicodeと絵文字、空結果の列定義、複数結果セット                                                      |
| 権限                 | 読み取り専用セッション、アプリ側の更新拒否、許可した更新、SELECT専用DBユーザーでの更新拒否           |
| 取得量               | 1,000行制限、保持サイズの制限と後続結果                                                              |
| エラーからの復帰     | SQLエラー、実行時間上限、クライアント側中断、その後の実行と再接続                                    |
| 接続                 | TLSの使用／不使用をサーバーのセッション状態で確認、認証失敗、DB不在、未信頼CAの拒否                  |
| 全件CSV              | 1,205行、長文、Unicode、引用符・改行、高精度小数、NULL、日時、バイナリ、上限超過時の既存ファイル保持 |
| TLS異常              | 実サーバーのホスト名不一致・期限切れ証明書を拒否                                                     |

中断テストはクライアント側の復帰を確認します。サーバー側の停止保証、永続トランザクション、ドライバー受信メモリ制限などIssue #19の未実装機能を検証済みとは扱いません。

## 結果と失敗時の調査

`test-results/mysql-relagrid-mysql-*/` にシナリオごとのテストログ、サーバーログ、`summary.json` を残します。レポートはGit管理対象外です。サマリーに実サーバーバージョン、シナリオ、成功件数、後片付け結果を記録します。エラー時は `failure.log` も確認してください。生成パスワードはログから除外します。

起動・認証・初期化失敗、テスト失敗、実行時間超過、実DBテストの未実行は非ゼロ終了になります。テスト0件やignoreされたままの状態を成功とは扱いません。テスト設定がない状態で無視対象のRustテストを直接実行しても、既定のroot／3307などへ接続せず失敗します。

TLSには `src-tauri/test-fixtures/tls/` の公開された試験専用証明書と鍵を使用します。正常系証明書は2036年9月に期限を迎えるため、それまでに更新が必要です。実サービスには使用しないでください。

通常の `cargo test` では8件の実DBテストをスキップします。CIへの登録はIssue #27で対応します。

## 内部の接続設定

実行スクリプトが子テストプロセスに渡す設定です。通常は手動指定不要です。

| 環境変数                                            | 内容                               |
| --------------------------------------------------- | ---------------------------------- |
| `RELAGRID_TEST_ISOLATED`                            | `true` 必須                        |
| `RELAGRID_TEST_HOST` / `RELAGRID_TEST_PORT`         | 専用サーバーの接続先               |
| `RELAGRID_TEST_DATABASE`                            | `relagrid_fixture_` で始まる専用DB |
| `RELAGRID_TEST_USERNAME` / `RELAGRID_TEST_PASSWORD` | テストユーザーの認証情報           |
| `RELAGRID_TEST_TLS`                                 | `true` または `false` 必須         |
| `RELAGRID_TEST_CA_PEM`                              | テスト用CA                         |
| `RELAGRID_TEST_SERVER_VERSION`                      | 起動時に確認した実バージョン       |

DB権限拒否のケースは同じパスワードの `fixture_reader` を使用します。スクリプトの初期化でこのSELECT専用ユーザーを作成します。

## 検証記録（2026-10-07）

Windows上のMySQL Community Server 26.7.0とNode.js 20.18.0で、同じコマンドを連続2回実行しました。各回ともTLSなし7件、TLSあり7件、ホスト名不一致1件、期限切れ1件の計16件が成功し、一時DBの削除と起動プロセスの終了を確認しました。

通常のRustテストは39件成功・実DB用8件スキップ、ClippyとRustfmtも成功しました。期待バージョンを意図的に不一致にした実行は非ゼロ終了しました。開発中の実接続テスト失敗時にも、専用サーバーとデータ領域が後片付けされることを確認しています。

MySQL 8.0およびLinuxでの実行、CI登録はこの検証に含みません。
