## 画面と状態

入口は[App](../../src/app/App.tsx) `App`。初期画面はリレーション、サイドバー・詳細パネルは表示、下部はアクティビティ。URLルーティングは使わずReact状態 `screen` で切り替える。

| 画面／領域       | 表示項目・操作                                                                     | 主な状態                                                     |
| ---------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 共通ヘッダー     | settings、リレーション／SQL、最小化・最大化・閉じる                                | 現在画面、Tauri判定                                          |
| 共通サイドバー   | 検索、接続／グループ一覧、スキーマ／テーブル一覧、追加・更新・切断                 | 未接続、復元中、接続中、操作中、エラー、選択接続・テーブル   |
| リレーション中央 | カラム付きノード、FK線、ズーム、ミニマップ、自動配置、全体表示                     | スキーマなし、選択、関連強調、ドラッグ位置                   |
| テーブル詳細     | 概要、カラム、依存関係。推定行数は通常「未取得」。主キー、型、NULL許可、参照元／先 | テーブル未選択、表示タブ。「データを表示」で下部プレビューへ |
| 下部パネル       | アクティビティとクリア、プレビュー表、全件CSV入口                                  | 未取得、取得中、0件、成功、失敗。NULLを区別して表示          |
| SQL上部          | 所有接続、読み取りモード、クエリタブ、編集、保存／全保存、実行、中断               | 未保存 `*`、実行中、中断待ち、保存中、復元失敗、別接続のタブ |
| SQL下部          | 結果／計画／メッセージ、複数結果、CSV、ページと10/25/100行選択                     | 未実行、結果0件、省略、未完了、実行全体失敗、保存通知（4秒） |
| SQL詳細          | 概要／履歴、参照テーブル・CTE、時間、返却／影響行数、モード、状態                  | 直近3件または50件。履歴クリックで所有接続付き新規タブ        |
| フッター         | 接続DB、READ ONLY／READ / WRITE、バージョン                                        | 切断時は未接続・READ ONLY                                    |

根拠：[Sidebar](../../src/features/explorer/Sidebar.tsx)、[TableDetails](../../src/features/explorer/TableDetails.tsx)、[BottomPanel](../../src/features/explorer/BottomPanel.tsx)、[QueryWorkspace](../../src/features/query/QueryWorkspace.tsx)。検索で絞るのはサイドバー一覧だけ。図のノードを除去する操作ではない。

## 遷移と保持

接続成功→関係図表示→テーブル選択→「データを表示」でプレビュー取得。接続操作でSQL画面に自動遷移するわけではない。SQL画面へ切り替えると所有接続が一致するタブを操作できる。別接続タブを選んでも自動再接続はしない。

画面切り替え時、`QueryWorkspace`自体はマウントを維持するが非表示時に `null` を返す。タブSQL・結果は親状態に残り、CodeMirrorインスタンスは再生成されるためカーソル／Undo状態の保存とは異なる。リレーション領域はCSSで非表示にする。

最後のクエリタブを閉じると新しい空タブになる。アプリのウィンドウ終了は `getCurrentWindow().close()` で、全未保存タブを確認する処理はない。タブ終了とアプリ終了を同じ仕様としない。
