# RG-05: 取得済み結果のCSV Export

2026-09-25。RG-04（`ad92c56`）に続く最初のExport単位。仕様の「取得済み結果のExport → 大容量ストリーム出力」の前半を実装した。全件取得と型保持形式を含むRG-05全体の完了ではない。

## 実装と既存動作

- 選択中のResult Setまたは実行計画の取得済み行を対象とする。現在ページだけでなく全ページを列順どおり出力する。出力開始時に結果の参照とファイル名を固定し、クエリを再実行しない。
- エクスポート画面に対象件数・列数、行や値の省略、未完了状態を表示する。汎用CSVのNULL→空文字と数式対策、UTF-8 BOM・ヘッダー・カンマ・CRLFを説明する。型情報が揃わないため型保持形式を提供できないことも表示する。
- `CsvExportDialog.tsx`は保存先選択、書き込み済み件数、エラー、中断、再試行を扱う。書き込み中は閉じて処理を見失うことを防ぎ、中断ボタンで停止する。コンポーネント破棄時も中断要求を送る。保存先ダイアログの取り消しはファイルを作成しない。
- `export.ts`はRG-04のwriterを1行ずつ使用する。文字コードの境界を維持してUTF-8で最大64KiBに分割し、各書き込みの完了を待つ。CSV全体の文字列・Blobをデスクトップ版で保持しない。追加メモリは1行と1チャンクに依存し、出力全件数に比例しない。元のクエリ結果は従来の上限内でエディタが保持する。
- Rustの`csv_export.rs`は同時出力を1つに制限し、出力IDでwrite/finish/abortを照合する。保存先はネイティブダイアログで取得し、任意のパスをフロントから書き込みAPIへ渡さない。
- 保存先と同じフォルダーに`.relagrid-export-*.partial`を作成する。書き込み失敗時はセッションを無効化して確定を防ぎ、完了時に同期してから保存先へ置き換える。通常の中断・失敗では一時ファイルを削除する。既存ファイルは確定前まで変更しない。確定処理が完了した後の中断は保存を取り消さない。
- アプリの強制終了などで残る`.partial`は未完成品であり、完成ファイルとして開く機能はない。削除失敗時はその状態をエラーとして扱う。プロセス強制終了・電源断からの再開は対象外。
- ブラウザのデモだけは既存のBlobダウンロードを維持する。メモリは取得済み結果の上限で制限されるが、全件サイズのBlobを生成する。ブラウザのディスク不足や保存完了をアプリは判定できないため、画面で制約を明示する。

ネイティブ保存ダイアログ用に`tauri-plugin-dialog`、同じフォルダーへの一時ファイル作成と確定用に`tempfile`を追加した。バージョンはCargo.lockで固定。ファイルシステム操作をフロントへ公開する権限は追加していない。ダイアログの呼び出しは[公式Rust API](https://docs.rs/tauri-plugin-dialog/latest/tauri_plugin_dialog/struct.Dialog.html)に従い、UIスレッドを塞がない場所で実行する。
